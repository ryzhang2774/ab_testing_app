# Embedded PDF typeface

`BusinessSansSC-Regular.ttf` is a static 400-weight, Unicode-range subset of
Google Fonts' Noto Sans SC. It is distributed under the accompanying SIL OFL 1.1
license. The original copyright notice and license are retained in `OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

Source font: `NotoSansSC[wght].ttf`, downloaded 2026-10-26. Build tool:
fonttools 4.62.0, `instantiateVariableFont(..., {"wght": 400})`, then subset
U+0020-00FF, U+2000-206F, U+2E80-9FFF, U+F900-FAFF, U+FF00-FFEF.
No network request or font conversion occurs when the app runs.

Asset SHA-256:
`55ccb94ff312bdb45ca2c4b5cbbb84e0257afe7e91caa83c51a0c8e2659f1918`.

This covers Latin and common Simplified Chinese input. Unsupported scripts or
rare CJK extension characters should be checked before sharing a report.

`DejaVuSans.ttf` is bundled separately for mathematical expressions (including
summation and square root symbols). It is distributed under the Bitstream Vera
license in `DejaVuSans-LICENSE.txt`; DejaVu changes are in the public domain.
Source: https://dejavu-fonts.github.io/; bundled copy from the local Poppler runtime.
